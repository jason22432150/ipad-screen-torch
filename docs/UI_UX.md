# UI / UX

## 發光與操作
UIKit root view 為均勻純色，填滿整個可用畫面；SwiftUI overlay 在 safe area 內。無永久狀態列、導覽列或底部選單。面板隱藏後無文字/圖示。面板空閒 5 秒後隱藏（非設定頁、非編輯或驗證流程；操作中重置計時）。初次啟動提供簡短教學與安全告知，可跳過/再次查看。四方向自適應，預設跟隨裝置，記憶方向鎖定偏好；尊重系統限制，iOS 15 不強制 Private API 旋轉。

| 手勢 | 動作 |
|---|---|
| 單指上/下 | 亮度增加/降低 |
| 單指左/右 | Kelvin 降/升；RGB 為 Hue；White 無效果 |
| 單擊空白 | 面板顯示/隱藏 |
| 雙擊空白 | 開/關燈 |
| 單指長按 | 進階設定 |
| 雙指長按 3 秒 | 預設完整鎖定解鎖 |
| 四指長按 5 秒 | 緊急關燈候選，須驗證系統衝突 |

單擊須等待雙擊判定；拖曳使用優勢軸避免同時改兩參數；面板控制項不得傳遞到底層手勢。手勢依介面方向，非硬體方向。初始建議：每完整畫面高度滑動對應 100% 亮度，每寬度對應全 Kelvin 範圍；相對起始值計算、邊界 clamp，最多每秒 30 次更新；實機調整靈敏度。VoiceOver 提供具名按鈕及無障礙 action，不依賴多指手勢；Dynamic Type、Reduce Motion。

## 畫面清單
L01 Lamp surface；L02 Quick panel（開關、要求/有效亮度、色溫/RGB 模式、最多 6 收藏、鎖定、計時與設定入口）；L03 顏色編輯（Hue/Saturation/RGB/HEX/Tint/校正）；L04 情境列表、編輯、排序及匯入；L05 倒數、排程列表及規則編輯、日出日落；L06 電源與安全設定；L07 手勢/方向/鎖定與 PIN；L08 啟動/資料備份與重設；L09 診斷/紀錄匯出；L10 安全復原/原因確認；L11 Guided Access 教學與狀態。設定頁不得被 5 秒隱藏；必要安全訊息可短暫覆蓋燈面。

## 鎖定
一般、部分（亮度/色彩/電源/情境獨立）、完整（僅解鎖/緊急停止）、專用（手動啟用 Guided Access）四層。部分鎖定下，會修改被鎖定欄位的情境操作整筆拒絕。鎖定只約束人為操作，不阻止既有自動化及安全。可選三指長按3秒、單指長按5秒、五連擊；PIN 4–6 位、Touch ID/裝置密碼可選，預設無 PIN。解鎖手勢先喚出認證，不直接繞過 PIN；忘記 PIN 可用系統身分驗證復原；沒有可用驗證時提供明確清除鎖定設定流程（防誤觸而非裝置安全邊界），不匯出 PIN。認證取消不得解鎖。鎖定/解鎖提示1.5秒。自動鎖定15/30秒、1/5/10分鐘，預設關閉，可依插電/電池或面板隱藏觸發，重啟記憶選用。
清潔模式15/30/60/120秒，黑色最低背光/白色/原照明可選；期間禁止一般手勢，退出恢復先前鎖定和照明，但安全停止與已觸發關燈不得被覆蓋。所有白光仍受有效亮度限制。
Guided Access 由使用者在設定→輔助使用啟用，三按 Home；App 偵測並教學，不自行強制單 App。若系統停用觸控則 App 解鎖與緊急手勢也無效，須用系統退出/電源鍵或拔電等實體處置；不要承諾攔截所有系統操作。
