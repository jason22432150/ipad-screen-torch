# 色彩與情境引擎

三種模式 Kelvin/RGB/White，各自獨立保存上次亮度/色彩；切換不破壞其他模式。Kelvin 1000…10000，step100，Tint -100…100（負洋紅、正綠）；RGB 0…255、HEX #RRGGBB（可接受無#後正規化）、Hue 0…360（360=0）、Saturation 0…100。RGB 以 sRGB triplet 為權威，Hue/Saturation 使用 HSV 作為編輯介面，保留 V 以無損呈現任意 RGB/HEX；App 照明亮度仍為獨立參數。純白直接 #FFFFFF，不受 Tint/色溫/手動色彩校正，最大白光輸出。左右滑動在 RGB 改 Hue，White 無動作。

## 初版近似演算法
T=clamp(K,1000,10000)/100，使用自然對數 ln，輸出 clamp 0…255：
- R: T≤66 =>255；否則 329.698727446*(T-60)^(-0.1332047592)
- G: T≤66 =>99.4708025861*ln(T)-161.1195681661；否則 288.1221695283*(T-60)^(-0.0755148492)
- B: T≥66 =>255；T≤19 =>0；否則 138.5177312231*ln(T-10)-305.0447927307
- 初始 Tint: G += 0.6*Tint，clamp；手動校正以可重設的每色頻 gain（建議0.5…1.5）處理 Kelvin/RGB，明確標示可能剪裁色域；最後套亮度軟體比例。色彩運算使用 Double，輸出前 clamp/round；無效值拒絕。公式、Tint/gain 為未校準提案；Night Shift、色彩濾鏡、面板老化可影響效果。設定頁提供原始/校正比較與重設。不承諾真實 CCT 或照度。
